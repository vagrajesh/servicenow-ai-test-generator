EXECUTIVE SUMMARY

Project Overview

This capstone project presents an enterprise-grade AI-powered test case generation system that revolutionizes Quality Assurance workflows by automating the creation of comprehensive test cases from user story requirements. The solution integrates Azure OpenAI’s GPT-4 with ServiceNow Test Management 2.0, delivering measurable improvements in efficiency, quality, and cost savings.

The Business Challenge

Enterprise QA teams face a critical bottleneck: manual test case creation consumes 3 hours per user story, limiting testing capacity and delaying releases. With 100+ user stories per month, this translates to 300+ hours of repetitive work, preventing QA engineers from focusing on strategic testing activities that require human expertise.

Financial Impact of Current State: - Labor Cost: $15,000/month in QA resources - Opportunity Cost: Delayed feature releases - Quality Cost: Inconsistent test coverage (60% standardization) - Scale Limitation: Cannot increase throughput without additional hiring

The Solution

An intelligent automation system that:

  1. Analyzes user story descriptions and acceptance criteria
  2. Leverages GPT-4 to generate 5-10 comprehensive test cases
  3. Creates fully-structured tests with detailed steps and expected results
  4. Automatically links tests to user stories via M2M relationships
  5. Monitors quality using DeepEval LLM evaluation framework
  6. Tracks costs and ROI in real-time
